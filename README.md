Browser-based Pac-Man clone built in vanilla JavaScript on a 400×440 HTML5 Canvas.

- 15×15 tile maze with dots and corner power pellets
- Four ghosts with distinct chase, scatter, and frightened AI behaviors
- Keyboard (WASD/arrows) and swipe/tap controls
- Lives system, extra life at 10,000 pts, escalating ghost-eat bonuses
- Title screen, help overlay, and full game loop

**Tech stack:** Vanilla JavaScript, HTML5 Canvas, ArcadeBase utilities.

**Run:** Open `index.html` in a modern browser, or run any static server (e.g., `npx serve`) from the project root.
